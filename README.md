## 👩🏽‍💻 About Me | Sobre mí

**EN 🇺🇸**

Hi! I'm Marilin Montes, a Software Development student at Universidad del Valle, Colombia.

I'm interested in understanding how software systems work beyond the code itself: how applications are deployed, how services communicate, how infrastructure is monitored, and how systems can be made more reliable and secure.

My learning journey has led me to explore Linux, Docker, service configuration, monitoring, Python, JavaScript, and the relationship between DevOps and cybersecurity.
