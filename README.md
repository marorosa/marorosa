# 👩🏽‍💻 Hi, I'm Maro Montes

### Software Development Student | DevOps · Cybersecurity · Infrastructure

I'm learning to build, deploy, monitor, and secure software systems — not just make applications work, but understand what happens behind the scenes.

My journey in software development has led me to explore Linux, Docker, service configuration, system monitoring, and the challenges of connecting different components into a working system.
